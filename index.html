Research

Current · Faculty-mentored apprenticeshipNortheastern University

Privacy & Safety Risks of LLM-Based Voice Assistants

What can a voice assistant remember, infer, or reveal about the people who share it?

I am investigating privacy and safety risks in LLM-based voice assistants, with an interest in how personal information is handled in shared-user settings.

Research approach
Literature review, controlled synthetic-user scenarios, and repeated probing to examine response consistency and information retention.
Evaluation focus
Distinguishing information recalled from supplied facts, inferences drawn from those facts, and unsupported claims.
Status
Ongoing research. Experimental design and pilot testing; results are not yet published.

Implementation notes ↓

What I built

A FastAPI backend, PostgreSQL event storage, a React dashboard, and a Python tracking SDK. Events can be grouped into persistent workflow traces.

A technical decision

Background SDK delivery keeps telemetry separate from the main application flow. The tradeoff is an in-memory queue that can lose pending events when a process exits.

Evidence & boundaries

The repository includes unit tests and CI. Quality and hallucination signals are lightweight heuristics; they are not validated factuality scores. Production authentication and tenancy remain future work.

classification

Leukemia classification · Python

I compared three classifiers on 72 leukemia samples with 7,129 expression features, and saved the predictions, evaluation tables, and plots.

Feature selection happens inside each cross-validation fold. With so few samples, the results need external validation before making broader claims.

scikit-learn pipelinesXGBoostStratified CV
Explore the repository ↗
View project details ↓

What I built

A reproducible analysis comparing logistic regression, random forest, and XGBoost on ALL versus AML classification, with PCA, ROC curves, and cross-validated predictions.

A technical decision

Place feature selection inside the pipeline so each training fold selects its own features. Selecting features on the full dataset before cross-validation would leak validation information.

Evidence & boundaries

Committed tables and figures support the displayed results. A 72-sample dataset limits generalization; cross-validation is not an independent external test. Full-data probe rankings are exploratory.
